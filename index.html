一時停止中はボタンが黄色に、黒画面中は赤になるので、今の状態がひと目で分かります。

画像・フェード・メモ・音

  • 画像：jpg・png などの画像もフォルダに入れておけば、動画と同じ順番で映せます。画像は次の合図まで映したままになります。
  • 切り替え：画面上部の「切り替え」で、パッと切り替えるか、フェード（0.5〜2秒で溶けるように切り替え）を選べます。黒画面に入るときも同じ速さで暗くなります。
  • きっかけメモ：一覧の ✎ を押すと、その動画を出すきっかけ（例：「〇〇のセリフの後」）を書けます。「次に流れる動画」の欄に大きく表示されます。書いたメモは自動で記録されます。
  • 音：一覧の 🔇／🔊 で、動画ごとに音を出すかを切り替えます（最初はすべて 🔇 音なし）。全体の音量は画面上部のつまみで調整します。手元のモニターからは音は出ません。
  • 別のパソコンで使うとき：一覧の上の「💾 メモを書き出す」で cue_settings.json を保存し、動画フォルダに入れておくと、フォルダを選んだときにメモと音の設定が読み込まれます。

映写画面をテレビ（Display2）に出す

  • Windows の「ディスプレイ設定」が 「表示画面を拡張する」 になっていることを確認（Windows キー ＋ P →「拡張」）。
  • 「🖥 映写画面を開く」を押すと黒い窓が開きます。手元の画面に出たら、黒い窓を1回クリックして Windows キー ＋ Shift ＋ →（または窓をドラッグ）でテレビ側へ移します。
  • テレビ側で黒い窓を ダブルクリック（または F11）すると全画面になります。

通知を止める方法

通知は、ソフトの側からは止められないので、Windows と Brave の設定で止めます。

  • Windows：「設定 → システム → 通知」で「応答不可」をオンにします。本番中だけオンにするのがおすすめです。
  • Brave：「設定 → プライバシーとセキュリティ → サイトの設定 → 通知」で「サイトに通知の送信を許可しない」を選びます。

H キー または ？ボタンで開閉、Esc キーで閉じます。
